# RAMBO COACH — versão funcional

Painel local para coach de Free Fire competitivo.

## O que já funciona
- Cadastro, edição e exclusão de jogadores
- Partidas, kills, dano total e headshots
- K/D automático = kills / partidas
- Dano médio automático = dano total / partidas
- HS% automático = headshots / kills
- Rating automático indicativo
- Registro e exclusão de partidas
- Dashboard calculado pelas partidas
- Cadastro de análises
- Agenda de treinos
- Salvamento no navegador com localStorage

## Como testar
1. Mantenha `index.html`, `style.css` e `script.js` na mesma pasta.
2. Abra `index.html` no navegador.
3. Os dados ficam salvos no navegador desse dispositivo.

## Publicação
Substitua os três arquivos correspondentes no mesmo repositório do GitHub Pages.
