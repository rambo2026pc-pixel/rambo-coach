# RAMBO COACH — versão inicial

Site de painel para coach de Free Fire competitivo.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. O site funciona localmente sem instalação.

## Arquivos
- index.html — estrutura das telas
- style.css — identidade visual e responsividade
- script.js — dados de demonstração e navegação

## Próxima etapa recomendada
Adicionar banco de dados, login do coach, cadastro real de jogadores, registro de partidas, VODs e gráficos de evolução.
